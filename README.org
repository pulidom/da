* Data assimilation
#+OPTIONS: ^:{}

This repository contains simple scripts of the following data assimilation methods:

- perturbed observations  EnKF (Burger et al 1996)
- ensemble transformed Kalman filter (ETKF, Hunt et al 2009),
- 3DVar variational DA.
- 4DVar

They are mainly with illustrative and pedagogical purposes.

** Main classes

*** Dynamical systems
They are all in the ~src/dyn.py~ file.

You will find classes for:

- Lorenz 1963: L63 class
- Lorenz 1996: L96
- Lorenz 1996 two scales: L96_2scl
- Lorenz 1996 with a linear parameterization (to mimic the 2 scales): L96lforcing

- Parent class: M
  - Define integration methods: RK4 and Euler
  - Initialize the true initial condition and the ensemble members (considering a spinup time)
*** Observation class

In the file ~src/obs.py~

- Define observational operator and observation covariance
- Generate synthetic observations

*** Filter class

It is located at the file ~src/enkf.py~

*** Variational DA classes

It is located at the file ~src/var.py~

- VAR3D
- VAR4D
- simple NMC method to generate background covariance in dynamical systems 
  
** Examples
